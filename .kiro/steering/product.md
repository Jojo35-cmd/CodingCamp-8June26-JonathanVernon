# Product

**Expense & Budget Visualizer** — a RevoU Coding Camp mini project by Jonathan Vernon.

A client-side personal finance tracker that lets users log expenses (name, amount, category), view a running total balance, and see spending distribution via a pie chart. All data is stored in the browser's Local Storage. No backend, no accounts, no server.

## Core Features
- Add transactions with name, amount, and one of three categories: Food, Transport, Fun
- Delete individual transactions
- Real-time balance total display
- Pie chart (Chart.js) showing spending by category
- Data persists across page reloads via Local Storage

## Constraints
- Pure client-side only — no frameworks, no backend
- Must work in current stable Chrome, Firefox, Edge, and Safari
- Loads and becomes interactive within 3 seconds on a 25 Mbps+ connection
